## Структура контента

```
/Game/TD/
  Units/<Имя>/        SM_/SK_, M_/MI_, T_, ABP_, BP_TD_Unit_<Имя>
  Enemies/<Имя>/
  Strikes/
  Maps/               L_TD_<NN>_<Место>, L_TD_Test_FirstPlayable
  Data/               DA_TD_*
  UI/                 WBP_TD_*, T_TD_UI_*
  Audio/              SW_/SC_TD_*
  FX/                 NS_TD_*
  Localization/       ST_TD_*
```

## Бюджеты (ориентир MVP)

| Ассет | Треугольники | Текстуры |
| --- | --- | --- |
| Пехота врага / расчёт | ≤ 3k | 1×1024 |
| Техника | ≤ 10k | 1×2048 |
| Юнит 2×2 | ≤ 12k | 1×2048 |
| Босс | ≤ 40k | 2×2048 |

LOD — автоматические (2 уровня). Пехота врага — общий скелет и общие анимации.

## Импорт

- Масштаб: 1 единица = 1 см; техника вписывается в свой размер на сетке (клетка 400 см).
- Ось вперёд — +X; точка привязки в центре футпринта на земле.
- Материалы — мастер-материалы проекта (`M_TD_Toon_Master`), инстансы на ассет.
