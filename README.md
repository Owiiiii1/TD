# TD — игра про войну в Украине

Мультяшный tower defense для ПК (Steam) на Unreal Engine. Игрок держит украинскую оборону и уровень за уровнем проходит реальные события войны. Наступают карикатурные русские войска на реальной советской технике.

**Статус:** пишется дизайн-документация. Рабочее название не выбрано.

## С чего начать

- [Docs/Pitch.md](Docs/Pitch.md) — что это за игра, человеческим языком.
- [Docs/STATUS.md](Docs/STATUS.md) — текущий этап, NEXT и открытые вопросы.
- [CLAUDE.md](CLAUDE.md) — правила для ИИ-агентов (Claude, Cursor).
