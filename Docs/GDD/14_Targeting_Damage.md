# Наведение и урон

**Статус:** черновик · **Пиллары:** 5, 1 · **Система:** S05 · **TDD:** будет позже

## Кратко

Каждый враг относится к одному классу цели, каждое оружие наносит один тип урона. Таблица «тип урона × класс цели» решает, кого чем бить. Брони и десятков характеристик нет: только множитель из таблицы.

## Фантазия игрока

«Javelin — по танкам, автомат — по пехоте, Stinger — по вертолётам. Всё как в жизни, и всё понятно с первого взгляда».

## Правила

1. У каждого врага один **класс цели**: Пехота, Лёгкая техника, Броня, Воздух, Море.
2. У каждого оружия один **тип урона**: Стрелковый, Фугасный, Противотанковый, Зенитный, Противокорабельный.
3. Урон по цели = базовый урон оружия × множитель из таблицы. Множитель 0 — оружие эту цель не атакует вообще.
4. Юнит стреляет автоматически по цели в радиусе, которую может поразить (множитель > 0).
5. **Приоритет цели** юнита задаёт игрок: «Первый» (ближе всех к рубежу, по умолчанию), «Сильный» (больше всего прочности), «Ближний» (ближе к юниту). Переключение — в панели юнита, в любой момент.
6. Фугасный урон бьёт по площади: все цели в радиусе взрыва получают урон по своему множителю.
7. У части оружия есть минимальная дальность (миномёт, гаубица): ближе неё стрелять нельзя.
8. Невидимых врагов (диверсанты, S13) атаковать нельзя, пока их не обнаружили.
9. Подавление: некоторые враги (авиация, десант, корабли) подавляют оборонительные юниты. Подавленный юнит не стреляет заданное время. У юнитов нет прочности, уничтожить их нельзя.

## Таблица эффективности

| Тип урона \ Класс цели | Пехота | Лёгкая техника | Броня | Воздух | Море |
| --- | --- | --- | --- | --- | --- |
| Стрелковый | 1,0 | 0,5 | 0,1 | 0,3* | 0 |
| Фугасный | 1,0 | 0,8 | 0,4 | 0 | 0,3 |
| Противотанковый | 0,3 | 1,2 | 1,5 | 0 | 0,5 |
| Зенитный | 0 | 0 | 0 | 1,5 | 0 |
| Противокорабельный | 0 | 0 | 0 | 0 | 2,0 |

\* Стрелковый урон по воздуху — только у юнитов с пометкой «бьёт по дронам и вертолётам» (МОГ, бабушка). У остальных стрелковых — 0. Стартовые значения, финальные — в балансе.

## Состояния юнита в бою

| Состояние | Переход |
| --- | --- |
| Ищет цель | → Стреляет, когда в радиусе есть подходящая цель |
| Стреляет | → Перезарядка после выстрела; → Ищет цель, если цель ушла или погибла |
| Перезарядка | → Стреляет или Ищет цель |
| Подавлен | → Ищет цель по окончании подавления |

## Формулы

**Урон:** `урон = базовый урон × множитель(тип, класс)`.
Пример: Javelin (ПТ, 100) по Т-72 (Броня): 100 × 1,5 = 150. Т-72 со 300 прочности уничтожается двумя попаданиями.

**Урон в секунду (для баланса):** `DPS = урон / перезарядка`.

**Фугас по площади:** все цели в радиусе взрыва получают полный урон по своему множителю, без спада к краю.

## Крайние случаи

- Цель вышла из радиуса во время полёта снаряда → снаряд долетает и наносит урон (снаряды самонаводящиеся, промахов нет).
- Две цели одинаково «первые» → берётся с меньшей прочностью.
- Юнит подавлен повторно во время подавления → таймер обновляется, а не складывается.
- Враг уничтожен, пока к нему летят снаряды нескольких юнитов → лишние снаряды исчезают, урон не переносится.

## Фидбек

- Цифры урона не показываются по умолчанию (настройка), зато видны полоски прочности врагов.
- Эффективное попадание (множитель ≥ 1,2) — крупный эффект и звук; слабое (≤ 0,3) — «звяк» и искры.
- Подавленный юнит — мигающий значок и дым; источник подавления подсвечен.

## UI

- В подсказке юнита иконки классов целей, которые он бьёт: зелёная — сильно, серая — слабо, нет иконки — не бьёт.
- Переключатель приоритета в панели выбранного юнита.

## Критерии приёмки

- [ ] Javelin не стреляет по воздуху, Stinger — по земле.
- [ ] Урон по каждому классу совпадает с таблицей.
- [ ] Миномёт не стреляет ближе минимальной дальности.
- [ ] Смена приоритета сразу меняет выбор цели.
- [ ] Подавленный юнит не стреляет заданное время, затем продолжает.

## Вне MVP

- Прочность и уничтожение оборонительных юнитов, ремонт.
- Промахи, баллистика, спад урона к краю взрыва.
- Броня по сторонам (борт, корма).
