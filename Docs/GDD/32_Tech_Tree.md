# Дерево технологий и донаты

**Статус:** черновик · **Пиллары:** 4, 1, 5 · **Система:** S22 · **TDD:** будет позже

## Кратко

Между уровнями игрок тратит донаты в дереве технологий: открывает новые юниты, супер-удары и уровень «Ветеран» для юнитов. Узлы становятся доступны по хронологии войны. Ключевые юниты уровня выдаются бесплатно, поэтому застрять из-за выбора нельзя.

## Фантазия игрока

«Армия на донатах: собрал — купил Bayraktar».

## Правила

1. Донаты начисляются после победы: 100 за прохождение + 50 за каждую звезду (S09). При переигровке — только за новые звёзды.
2. Донаты копятся между уровнями и не сгорают.
3. Узел дерева — одно из трёх: новый юнит, новый супер-удар или уровень III «Ветеран» для уже открытого юнита.
4. У узла есть «доступен с уровня N»: раньше его купить нельзя (хронология).
5. Узел «Ветеран» доступен, когда открыт сам юнит.
6. **Ключевые юниты** выдаются бесплатно перед уровнем, где они нужны, если игрок их не купил: Stinger (ур. 2), Javelin (ур. 3), «Паляница» (ур. 4), Фермер с трактором (ур. 6), «Нептун» (ур. 10).
7. Купленный узел нельзя продать. Сброса дерева в MVP нет.
8. Дерево открывается кнопкой на карте кампании и на экране итога.

## Параметры тюнинга

DataAsset дерева: узлы, ветки, цены, уровень доступности, ключевые выдачи. Общие настройки: донаты за прохождение и за звезду.

## Крайние случаи

- Игрок переиграл уровень с ★ на ★★★ → +100 донатов.
- Ключевой юнит куплен заранее → бесплатная выдача пропускается, донаты не возвращаются (купить раньше нельзя — узлы доступны не раньше уровня).

## Фидбек

- Покупка узла: печать «Закуплено на донаты», звук.
- Новый доступный узел: точка на кнопке «Технологии».

## UI

- Экран дерева: ветки колонками, узлы с иконкой юнита, ценой и «с уровня N»; заблокированные — серые с подписью уровня.
- Баланс донатов вверху экрана.

## Критерии приёмки

- [ ] Донаты начисляются по формуле; переигровка даёт только за новые звёзды.
- [ ] Узлы недоступны раньше своего уровня.
- [ ] Ключевые юниты выдаются бесплатно перед своим уровнем.
- [ ] Открытый узел появляется в панели постройки или ударов.
