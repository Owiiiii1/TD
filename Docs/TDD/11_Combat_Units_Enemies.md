# Бой: юниты, враги, урон, особые угрозы — архитектура

**Статус:** черновик · **GDD:** [13](../GDD/13_Defense_Units.md), [14](../GDD/14_Targeting_Damage.md), [15](../GDD/15_Enemies.md), [18](../GDD/18_Super_Strikes.md), [19](../GDD/19_Air_Threats.md), [22](../GDD/22_Paratroopers.md), [23](../GDD/23_Stealth.md), [24](../GDD/24_Naval.md), [25](../GDD/25_Bosses.md), [26](../GDD/26_Morale.md), [27](../GDD/27_Tractor_Trophies.md) · **ADR:** [0003](../ADR/ADR_0003_Singleplayer_No_GAS.md), [0004](../ADR/ADR_0004_Data_Driven.md)

## Обзор

Юнит — актор с `UTD_WeaponComponent`, который по таймеру ищет цель и наносит урон через `UTD_DamageLibrary`. Враг — актор с прочностью, тегами и `UTD_RouteFollowerComponent`; особые свойства — `UTD_EnemyTraitComponent` с поведением по тегу. Супер-удары — `UTD_SuperStrikeComponent` на контроллере. Всё без GAS.

## Классы

| Класс | Тип | Ответственность |
| --- | --- | --- |
| `ATD_DefenseUnit` | Actor | Данные юнита, уровень, клетки; содержит оружие и подавление |
| `UTD_WeaponComponent` | ActorComponent | Таймер перезарядки, поиск цели по приоритету, выстрел, визуальный снаряд |
| `UTD_SuppressionComponent` | ActorComponent | Подавлен до времени T; сообщает оружию |
| `UTD_TractorComponent` | ActorComponent (на фермере) | Очередь обломков в радиусе, буксировка, награда, шанс трофея |
| `ATD_Enemy` | Actor | Данные врага, прочность, теги, смерть, награда; состояния видимости и отступления |
| `UTD_EnemyTraitComponent` | ActorComponent | Поведение по тегам: подавление, высадка, высадка при гибели, барахло, заход штурмовика, отступление |
| `ATD_Wreck` | Actor (пул) | Обломок 10 с, ссылка на данные врага |
| `ATD_ProjectileVisual` | Actor (пул) | Только визуал: летит к цели за время T |
| `UTD_DamageLibrary` | BlueprintFunctionLibrary | `ApplyDamage(Target, DamageTag, Amount, Source)`, `ApplyAreaDamage(Center, Radius, ...)` по таблице |
| `UTD_SuperStrikeComponent` | ActorComponent на контроллере | Прицеливание, перезарядки, исполнение ударов по типу эффекта |
| `UTD_EnemyRegistry` | Объект внутри `ATD_GameMode` | Список живых врагов для поиска целей (не Subsystem) |

## Поиск цели

1. Таймер перезарядки истёк → `UTD_WeaponComponent` берёт врагов из `UTD_EnemyRegistry`.
2. Фильтр: в радиусе (и дальше минимальной дальности), множитель урона > 0, атакуем (не невидим или обнаружен), для стрелкового по воздуху — пометки юнита.
3. Выбор по приоритету: «Первый» — максимальный прогресс по маршруту; «Сильный» — максимальная прочность; «Ближний» — минимальная дистанция.
4. Выстрел: время полёта = дистанция / скорость визуала; урон применяется по таймеру попадания; если цель мертва — урон теряется.
5. Перебор целей — линейный по реестру (≤150), не чаще перезарядки.

## Урон

`Урон = Amount × DamageTable[DamageTag][TargetTag] × (1 + бонус ведьм)`. Прочность ≤ 0 → смерть: награда в `ATD_GameState`, обломок (если техника), свойство «при гибели», событие для энциклопедии и счётчика «Набито».

## Особые угрозы

| Свойство (тег) | Реализация |
| --- | --- |
| Stealth | Флаг `bRevealed` + таймер; «Паляница» и наблюдатели ставят `RevealedUntil` |
| Suppressor | Таймер свойства: найти юнит(ы) в радиусе → `Suppression->Suppress(Duration)` |
| Paratrooper / Transport | Транспорт летит по воздушному маршруту к зоне высадки → спавн десантников в зоне → им назначается маршрут зоны (из `ATD_GridVolume`) после прямого выхода к точке |
| DismountOnDeath | При гибели спавн N пехотинцев на текущей дистанции маршрута |
| StrikeRun | При появлении выбрать точку максимальной плотности юнитов, пролететь, подавить в радиусе |
| FlyToBorder | Воздушный маршрут до рубежа, урон рубежу |
| Retreats | При первом пересечении 30% прочности — бросок шанса → `RouteFollower.Direction = -1`, у точки появления — уход с 50% награды |

Боссы — те же враги с данными `UTD_BossData` и полосой прочности в UI.

## Супер-удары

Типы эффекта: Damage (площадь/цели), Slow (зона замедления + бонус урона), Reveal (зона обнаружения), AirWipe (процент прочности всем воздушным). Параметры — `UTD_SuperStrikeData`.

## Производительность

- Юниты и свойства — таймеры, не Tick.
- Пулы: визуальные снаряды (300), обломки (40), эффекты.
- Реестр врагов — массив, удаление swap-remove.

## Анти-паттерны

- Не вводить прочность юнитов (вне MVP).
- Не делать физические снаряды и столкновения.
- Не писать отдельный класс на каждого врага: различия — в данных и тегах.

## Тесты и проверка

- Automation: таблица урона по всем парам; приоритеты целей; подавление и его обновление; шанс отступления (детерминированный сид); награды.
- Ручная: сценарий First_Playable.

## Риски

| Риск | Митигация |
| --- | --- |
| Линейный поиск целей при 40 юнитах × 150 врагов | Только по таймеру перезарядки; при проблеме — сетка-бакеты |
| Перегруз `UTD_EnemyTraitComponent` | При > 400 строк — разделить на компоненты по свойству |
