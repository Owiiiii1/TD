## Статус

## Цель
Минимальный HUD на CommonUI + MVVM: рубеж, е-бали, волна, таймер, кнопка волны, предпросмотр, панель постройки, панель юнита, пауза и ×2.

## Что прочитать перед началом
- `CLAUDE.md`, [Coding_Rules](../Coding_Rules.md), [Workflow](../Workflow.md)
- [GDD/40](../../GDD/40_UI_UX.md), [TDD/14](../../TDD/14_UI.md), [ADR-0009](../../ADR/ADR_0009_UI_CommonUI_MVVM.md)

## Объём работ
- `UTD_HUDViewModel`, `UTD_BuildPanelViewModel`, `UTD_SelectedUnitViewModel`.
- C++-база экрана HUD в `TDUIRuntime`.
- String Table `ST_TD_UI` (uk, en) для текстов HUD.

## Вне объёма
- Остальные экраны (M3), удары (TD-010), лента событий.

## Файлы
- `TDUIRuntime/ViewModels/*`, `TDUIRuntime/Screens/TD_HUDScreen.*`

## Действия владельца в Editor
Сверстать `WBP_TD_HUD` по зонам GDD/40 на примитивных стилях, привязать к ViewModel.

## Критерии приёмки
- [ ] Собирается TDEditor Win64 Development без новых предупреждений.
- [ ] Нет чисел баланса в C++.
- [ ] Нейминг по Coding_Rules.
- [ ] TDD обновлён: TDD/14.
- [ ] Все поля обновляются по событиям, без Tick.
- [ ] Кнопки постройки, улучшения, продажи, волны, паузы и ×2 работают мышью.
- [ ] Тексты из String Table, переключаются на английский.

## Ручная проверка
PIE на тестовом уровне, пройти 3 волны только через HUD.
