# ADR-0003 — Одиночная игра: без сети и без GAS

## Статус
Принято

## Контекст
GrimProtocol строился multiplayer-first и GAS-first, что сильно усложнило каждую систему. TD — одиночная кампания без мультиплеера (GDD/00), механики простые: урон по таблице, подавление, замедление.

## Решение
- Сети нет: никакой репликации, RPC и авторитета сервера. Вся логика локальная.
- GAS не используется. Урон, подавление, замедление, перезарядки — простой C++ в компонентах, числа из DataAsset.
- Gameplay Tags используются как таксономия (классы целей, типы урона, свойства), без GAS.

## Последствия
### Плюсы
- Код каждой системы в разы проще; задачи для Cursor меньше.
- Нет ошибок синхронизации.
### Минусы
- Добавить мультиплеер позже — переписывание (вне игры по GDD).
- Нет готовой системы эффектов GAS — пишем свои 3 эффекта (подавление, замедление, обнаружение).

## Рассмотренные альтернативы
- GAS ради «на будущее» — запрещено ADR-0005.
