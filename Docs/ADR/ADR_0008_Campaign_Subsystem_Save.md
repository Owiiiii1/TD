# ADR-0008 — Кампания в GameInstanceSubsystem, один SaveGame

## Статус
Принято

## Контекст
Прогресс кампании (звёзды, донаты, дерево, энциклопедия) живёт между уровнями и сохраняется на диск.

## Решение
- `UTD_CampaignSubsystem` (`UGameInstanceSubsystem`) хранит состояние кампании в памяти и сохраняет его. Жизненный цикл = жизненный цикл игры — это единственный разрешённый Subsystem (ADR-0005).
- Сохранение — `UTD_SaveGame`, один слот, автосохранение после итога уровня и покупки в дереве.
- Настройки — отдельно, через стандартные `UGameUserSettings` + свой слот для языка и управления.

## Последствия
Простое сохранение без слотов. Облачные сохранения Steam — после MVP.
