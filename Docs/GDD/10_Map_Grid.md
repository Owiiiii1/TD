# Карта и сетка

**Статус:** черновик · **Пиллары:** 3, 5, 1 · **Система:** S01 · **TDD:** будет позже

## Кратко

Каждый уровень — 3D-карта реального места, на которую наложена плоская квадратная сетка. Сетка определяет, где проходят дороги врага, где можно строить и что недоступно. Игрок видит сетку только в режиме постройки.

## Фантазия игрока

«Я смотрю на знакомое место сверху, как командир на карту, и выбираю, где окопаться».

## Правила

1. Игровое поле — прямоугольная сетка квадратных клеток. Одна клетка ≈ 4 × 4 м мира (стартовое значение).
2. Каждая клетка имеет ровно один тип (таблица ниже). Тип задаётся при создании уровня и в бою не меняется.
3. Строить можно только на клетках типа «Земля». Юнит занимает 1×1 или 2×2 клетки; все его клетки должны быть «Землёй» и свободны.
4. На клетках «Дорога» строить нельзя, кроме дорожных препятствий (ежи и подобное), — они ставятся только на дорогу.
5. Сетка игровая плоская: рельеф и высоты — только визуал, на дальность и урон не влияют.
6. Прямой видимости нет: юнит стреляет по любой цели в радиусе, стены и лес не закрывают обзор.
7. Размер поля — от 24 × 16 до 48 × 32 клеток (стартовые значения). Камера не выходит за границы поля с небольшим запасом.
8. Каждая карта содержит минимум одну точку появления врага и минимум один рубеж — конец дорог, где враг снимает очки рубежа.

## Типы клеток

| Тип | Строить | Враг ходит | Пример |
| --- | --- | --- | --- |
| Земля | Да | Нет | Поле, двор, обочина |
| Дорога | Только дорожные препятствия | Да (наземные) | Трасса, просёлок, улица |
| Вода | Нет | Да (корабли — S14) | Море, река |
| Препятствие | Нет | Нет | Здание, лес, руины, обрыв |
| Зона высадки | Нет | Десант приземляется (S12) | Поле у аэродрома |
| Появление врага | Нет | Старт маршрутов | Край карты, порт |
| Рубеж | Нет | Конец маршрутов | Блокпост, мост, город |

Авиация летит над сеткой и типы клеток игнорирует (S11).

## Состояния и переходы

Клетка «Земля» бывает в двух состояниях:

| Состояние | Переход |
| --- | --- |
| Свободна | → Занята, когда на неё поставлен юнит |
| Занята | → Свободна, когда юнит продан (уничтожить юнит нельзя — S05) |

Остальные типы состояния не меняют.

## Формулы

**Можно ли построить:**
`можно = все клетки футпринта ∈ поле И тип = Земля И свободны`
(для дорожных препятствий — `тип = Дорога И свободны от других препятствий`).

**Дальность:** расстояние между центрами клеток в клетках, по евклиду.
Пример: юнит в (10, 10), цель в (13, 14) → √(3² + 4²) = 5 клеток.

## Крайние случаи

- Юнит 2×2 частично касается дороги → постройка запрещена.
- Юнит продан → клетки освобождаются сразу.
- Курсор вне поля в режиме постройки → призрак юнита красный, постройка невозможна.
- Две дороги рядом через одну клетку «Земли» → постройка 1×1 возможна, 2×2 — нет.

## Фидбек

- В режиме постройки: сетка проступает на земле; зелёный призрак — можно, красный — нельзя; подсвечен радиус юнита.
- Дорожные клетки подсвечены отдельно, чтобы было видно, куда пойдёт враг.
- Вне режима постройки сетка не видна, карта выглядит как живая местность.

## UI

- Переключатель «показывать сетку всегда» в настройках.
- Подсказка при наведении на клетку «Препятствие»: «Здесь не построить».

## Критерии приёмки

- [ ] На тестовой карте нельзя поставить юнит на дорогу, воду, препятствие и за краем поля.
- [ ] Юнит 2×2 ставится только на 4 свободные клетки «Земли».
- [ ] После продажи юнита на его место можно сразу поставить другой.
- [ ] Сетка видна только в режиме постройки (или всегда, если включено в настройках).
- [ ] Камера не уходит за границы поля дальше заданного запаса.

## Плейтест-сценарии

| Сценарий | Ожидание |
| --- | --- |
| Новичок впервые открывает постройку | Сразу понимает, где можно строить, без подсказки |
| Игрок пытается перекрыть дорогу юнитами | Невозможно: на дорогу ставятся только препятствия, не блокирующие путь |
| Плотная застройка у развилки | Видно, где осталось место для 2×2 |

## Вне MVP

- Рельеф с игровым эффектом (высоты дают дальность).
- Разрушаемые препятствия и расчистка клеток.
- Прямая видимость и укрытия.
