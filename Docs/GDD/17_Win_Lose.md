# Рубеж, победа, поражение, звёзды

**Статус:** черновик · **Пиллары:** 2, 5 · **Система:** S09 · **TDD:** будет позже

## Кратко

Рубеж — очки обороны уровня. Враг, дошедший до конца маршрута, снимает очки рубежа. Рубеж на нуле — поражение. Все волны пройдены и рубеж устоял — победа и от одной до трёх звёзд.

## Фантазия игрока

«Ни один не прошёл — три звезды».

## Правила

1. В начале уровня рубеж = 20 очков (стартовое значение, задаётся уровнем).
2. Враг, дошедший до рубежа, снимает столько очков, сколько указано у него (S06): пехота 1, техника 2, броня 3, босс — по данным босса.
3. Воздушные враги, летящие к рубежу (Орлан, позже «Шахеды»), снимают очки, если долетели.
4. Рубеж = 0 → поражение сразу, даже если на поле ещё есть враги.
5. Все волны пройдены и рубеж > 0 → победа.
6. Звёзды: ★★★ — рубеж ≥ 90% начального; ★★ — ≥ 50%; ★ — любая победа.
7. При поражении игрок может начать уровень заново или выйти на карту кампании.

## Состояния и переходы

| Состояние | Переход |
| --- | --- |
| Бой | → Поражение, когда рубеж = 0; → Победа, когда пройдена последняя волна |
| Победа | → Экран итога (S18) |
| Поражение | → Экран поражения: «Заново» / «На карту» |

## Формулы

`звёзды = 3, если рубеж ≥ 0,9 × начальный; 2, если ≥ 0,5; иначе 1`.
Пример: начальный 20, осталось 17 → 85% → ★★.

## Параметры тюнинга

| Параметр | Стартовое значение | Диапазон | Где живёт |
| --- | --- | --- | --- |
| Начальный рубеж | 20 | 10–50 | Данные уровня |
| Порог ★★★ | 90% | 80–100 | Общие настройки |
| Порог ★★ | 50% | 30–70 | Общие настройки |

## Крайние случаи

- Последний враг последней волны доходит и обнуляет рубеж → поражение (поражение проверяется раньше победы).
- Рубеж уходит в минус (враг снимает 3 при остатке 1) → ровно 0, поражение.

## Фидбек

- Потеря рубежа: тряска счётчика, тревожный звук, вспышка у рубежа.
- Победа: «Рубеж устоял!», звёзды по одной.
- Поражение: экран врага «Всё идёт по плану» и толстый орк-свинья с флажком.

## UI

- Счётчик рубежа вверху рядом с е-балями; при ≤ 25% — красный.

## Критерии приёмки

- [ ] Рубеж уменьшается на урон дошедшего врага.
- [ ] При 0 — сразу поражение; при прохождении всех волн — победа.
- [ ] Звёзды считаются по порогам.
