## Камера и управление

Камера переносится из GrimProtocol (`AGP_CameraPawn`, конфиг-DataAsset, ограничивающий объём карты), добавляется управление стрелками.

| Действие | Мышь / клавиатура |
| --- | --- |
| Перемещение камеры | WASD, стрелки, курсор у края экрана |
| Вращение камеры | Средняя кнопка мыши (зажать и вести); Q / E — шаг 45° |
| Приближение | Колесо мыши, в ограниченных пределах |
| Выбор юнита | ЛКМ |
| Постройка | Клик в панели или 1–9; ЛКМ — поставить; Shift — ставить подряд; ПКМ / Esc — отмена |
| Супер-удары | Клик в панели или Z, X, C, V, B; ЛКМ — точка; ПКМ / Esc — отмена |
| Пауза | Пробел |
| Скорость ×1 / ×2 | Tab |
| Показать радиусы | Alt (зажать) |

Все клавиши переназначаются в настройках.

## Скорость и пауза

- Пауза в любой момент; на паузе можно строить, улучшать, продавать и выбирать точку супер-удара.
- Скорость ×2 доступна всегда (решено: да).

## Локализация

- Языки: украинский (основной), английский.
- Все тексты в таблицах строк, никакого текста в коде и текстурах.
- Шрифт с кириллицей и латиницей, единый стиль.
- Термины-мемы переводятся с адаптацией, а не дословно; к каждому — пояснение для переводчика.

## Доступность

- Классы целей различаются и цветом, и формой иконки.
- Размер интерфейса 80–150%.
- Субтитры к репликам (если будут).

## Взаимодействие с другими системами

Отображает состояние всех систем; ввод передаёт в S03 (постройка), S10 (удары), S05 (приоритет), S18 (поток).

## Критерии приёмки

- [ ] Всё управление из таблицы работает и переназначается.
