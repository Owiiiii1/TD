# Арт и аудио

**Статус:** черновик · **Пиллары:** 1, 2 · **Система:** S21 · **TDD:** будет позже

## Кратко

Мультяшная 3D-война в духе SWINE: крупные читаемые силуэты реальной техники с утрированными пропорциями, яркие свои и грязные чужие. Камеру можно вращать, поэтому все юниты и враги — полноценные 3D-модели. Ассеты для MVP генерируются ИИ и доводятся вручную по единому стайлгайду.

## Визуальный стиль

- **Пропорции:** техника «пухлая» и укороченная (как игрушка), стволы и ракеты утрированы; узнаваемость модели по силуэту обязательна.
- **Читаемость сверху:** силуэт и цвет различимы с максимального отдаления камеры.
- **Свои:** чистая техника, пиксельный камуфляж, жёлто-синие акценты (ленты, нашивки), бодрые позы.
- **Враги:** орк-свинья (свиное рыло, клыки, маленькие глазки, грязная форма), ржавая техника, «Z» и «V», привязанное награбленное (унитазы, стиральные машины, ковры, телевизоры).
- **Смерть и разрушение:** мультяшно, без крови и натурализма: дым, разлетающиеся детали, убегающие в кусты орки, падающее барахло.
- **Карты:** узнаваемые места в упрощённом виде (аэродром Гостомеля, трасса у Броваров, остров Змеиный), тёплая палитра, ясные дороги.
- **UI:** военная планшетка, трафаретный шрифт для заголовков, читаемый шрифт для текста.

## Аудио

- **Музыка:** бодрый украинский рок/электроника для боя, спокойная тема для карты. Только лицензированная или заказная, без известных песен-мемов с правообладателем.
- **Звуки:** узнаваемый звук для каждого оружия; мультяшные звуки гибели врага; звуковые мемы без прямых цитат правообладателей.
- **Реплики:** текстом; озвучка — вне MVP.

## Пайплайн генерации ассетов

1. **Стайлгайд:** 5–10 эталонных концептов (свой юнит, враг-пехота, вражеская техника, карта, UI) утверждаются владельцем до массового производства.
2. **Концепт:** генерация изображения по шаблону промпта со стайлгайдом и референсами реальной модели.
3. **3D:** генерация модели по концепту (image-to-3D), ретопология и UV по необходимости, бюджет полигонов (TDD).
4. **Доработка:** правка пропорций, материалы по палитре проекта, проверка узнаваемости.
5. **Анимации:** простые (стрельба, гибель, ходьба) — риг и библиотеки анимаций; без сложной мимики.
6. **Импорт в Unreal** по правилам нейминга (TDD) и проверка в игре с максимального отдаления.
7. **Учёт:** для каждого ассета — пометка «сгенерировано ИИ» в реестре ассетов, для раздела AI Generated Content Disclosure на Steam.

## Правила контента

- Никаких реальных людей, лиц, гербов и логотипов компаний и фондов.
- Реальная техника — по силуэту, без копирования чужих 3D-моделей и фотографий.
- Границы тона [Pitch](../Pitch.md#границы-тона).

## Критерии приёмки

- [ ] Стайлгайд утверждён до производства юнитов этапа 1.
- [ ] Каждый юнит и враг этапа 1 узнаётся по силуэту с максимального отдаления камеры.
- [ ] Реестр ассетов отмечает сгенерированные ассеты.

## Вне MVP

- Озвучка, анимированные заставки, лицевые анимации.
