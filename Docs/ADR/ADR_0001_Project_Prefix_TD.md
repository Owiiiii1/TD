# ADR-0001 — Префикс проекта `TD`

## Статус
Принято

## Контекст
Название игры не выбрано, а имена классов и ассетов нужны с первого коммита кода. Менять префикс позже дорого: он во всех классах, ассетах и путях.

## Решение
- Префикс кода и ассетов — `TD` (Tower Defense), не зависит от будущего названия игры.
- Классы: `ATD_*`, `UTD_*`, `FTD_*`, `ETD_*`, `ITD_*`.
- Модули: `TDRuntime`, `TDUIRuntime`, `TDEditor` (по необходимости).
- Путь контента: `/Game/TD/`.
- Ассеты: `<Тип>_TD_<Имя>`, например `DA_TD_Unit_Javelin`, `BP_TD_Enemy_T72`, `WBP_TD_HUD`.
- Gameplay Tags: корень `TD.`

## Последствия
### Плюсы
- Имена стабильны при смене названия игры.
### Минусы
- Префикс не совпадает с маркетинговым названием — допустимо.

## Рассмотренные альтернативы
- Префикс по названию игры — названия нет.
- Без префикса — конфликты с движком и плагинами.
