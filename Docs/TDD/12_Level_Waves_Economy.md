# Уровень, волны, экономика, рубеж — архитектура

**Статус:** черновик · **GDD:** [16_Waves](../GDD/16_Waves.md), [17_Win_Lose](../GDD/17_Win_Lose.md), [30_Balance_Economy](../GDD/30_Balance_Economy.md)

## Обзор

`ATD_GameMode` запускает уровень по `UTD_LevelData`. `UTD_WaveDirectorComponent` ведёт волны. `ATD_GameState` хранит е-бали, рубеж, номер волны и рассылает изменения делегатами.

## Классы

| Класс | Ответственность |
| --- | --- |
| `ATD_GameMode` | Загрузка данных уровня, старт, реестр врагов, проверка победы и поражения, итог |
| `ATD_GameState` | Е-бали, рубеж, волна, таймер, счётчик «Набито», делегаты `OnEBaliChanged`, `OnBorderChanged`, `OnWaveChanged` |
| `UTD_WaveDirectorComponent` | Фазы: Подготовка, Волна, Таймер; спавн групп по таймерам; ранний вызов и бонус; завершение волны |
| `ATD_PlayerController` | Ввод, пауза, скорость (×1/×2 через `SetGlobalTimeDilation`) |

## Поток уровня

1. `BeginPlay` GameMode: данные уровня → стартовые е-бали и рубеж → ключевые выдачи учтены кампанией → фаза Подготовка.
2. Кнопка «Следующая волна» → фаза Волна: группы спавнятся по задержкам и интервалам на своих маршрутах.
3. Все группы заспавнены → фаза Таймер.
4. Волна завершена (её враги выбыли) → бонус волны.
5. Последняя волна завершена и рубеж > 0 → победа → звёзды → `UTD_CampaignSubsystem::ReportLevelResult`.
6. Рубеж ≤ 0 → поражение (проверяется первым).

## Пауза и скорость

- Пауза — `SetPause`, но постройка разрешена: `UTD_BuildComponent` и UI работают при паузе (`bTickEvenWhenPaused` на нужных объектах).
- ×2 — глобальная дилатация времени; таймеры игровые, UI — реальные.

## Тесты и проверка

- Automation: волна из 2 групп спавнит нужное количество на нужных маршрутах; ранний вызов даёт бонус; рубеж 0 → поражение раньше победы; звёзды по порогам.
- Ручная: First_Playable.
