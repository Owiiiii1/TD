# Кампания, дерево технологий, энциклопедия, сохранения — архитектура

**Статус:** черновик · **GDD:** [28_Level_Campaign_Flow](../GDD/28_Level_Campaign_Flow.md), [29_Encyclopedia](../GDD/29_Encyclopedia.md), [32_Tech_Tree](../GDD/32_Tech_Tree.md) · **ADR:** [0008](../ADR/ADR_0008_Campaign_Subsystem_Save.md)

## Обзор

`UTD_CampaignSubsystem` хранит прогресс: звёзды уровней, донаты, купленные узлы, открытые записи энциклопедии, выбранную сложность. Сохраняет в `UTD_SaveGame` после каждого изменения прогресса.

## Классы

| Класс | Ответственность |
| --- | --- |
| `UTD_CampaignSubsystem` | Прогресс, правила донатов, покупка узлов, ключевые выдачи, открытие записей, загрузка и сохранение |
| `UTD_SaveGame` | Сериализуемое состояние (версия формата) |

## Данные сохранения

```
Version
Difficulty
Map<LevelId, BestStars>
Donaty
Set<TechNodeId> Purchased
Set<FName> GrantedKeyItems
Set<EntryId> UnlockedEntries
Map<EntryId, bool> Seen    ← для точки «новое»
```

## Правила

- `ReportLevelResult(LevelId, Stars)`: если впервые — +100 донатов; плюс 50 × (Stars − прежние лучшие звёзды, если больше 0).
- `CanPurchase(Node)`: хватает донатов, номер следующего уровня ≥ «доступен с», для «Ветерана» — юнит открыт.
- `GetAvailableUnits(LevelId)` = купленные + ключевые выдачи до этого уровня включительно.
- Энциклопедия: игровые события (встреча врага, первая гибель варианта, трофей, открытие юнита, пройден уровень) → `UnlockEntry`.

## Версия сохранения

Поле Version; при росте — функция миграции. Несовместимое сохранение — предупреждение и новый профиль (без падения).

## Тесты

- Automation: донаты при первом прохождении и переигровке; узел недоступен раньше уровня; ключевые выдачи; сохранение → загрузка совпадают.
