# Баланс: экономика

**Статус:** черновик · **Пиллары:** 5, 3 · **Система:** S08 · **TDD:** будет позже

Две валюты: **е-бали** внутри уровня (строить и улучшать) и **донаты** между уровнями (дерево технологий, [32_Tech_Tree](32_Tech_Tree.md)). Все числа — стартовые, проверяются плейтестом.

## Е-бали: источники

| Источник | Сколько | Где задаётся |
| --- | --- | --- |
| Стартовый пакет уровня | 300 (ур. 1) → 600 (ур. 10) | Данные уровня |
| Уничтожение врага | Награда врага: 5–80, боссы 300–1000 | DataAsset врага |
| Вариант / барахло | +10–20 | DataAsset врага |
| Пройденная волна | 20 + 5 × номер волны | Общие настройки |
| Ранний вызов волны | 1 за каждую оставшуюся секунду таймера | Общие настройки |
| Трактор | 10 за лёгкую технику, 25 за броню | Общие настройки трофеев |
| Отступивший враг | 50% награды | Общие настройки морали |

## Е-бали: стоки

| Сток | Сколько |
| --- | --- |
| Постройка | 50–600 (таблица [S04](13_Defense_Units.md)) |
| Улучшение II | 60% цены юнита |
| Улучшение III | 90% цены юнита |
| Продажа | Возврат 70% (100% до следующей волны) |

## Целевой баланс уровня

- К середине уровня игрок может держать 6–10 юнитов, к концу — 10–16 при ★★.
- Награды волны ≈ 70–90% стоимости юнитов, нужных против следующей волны: игрок всегда чуть «в обрез».
- Ранний вызов даёт до +15% е-балей за уровень опытному игроку.

## Донаты

| Источник | Сколько |
| --- | --- |
| Победа на уровне | 100 |
| Каждая звезда | 50 |
| Переигровка | Только за новые звёзды |

Сток — узлы дерева (80–250 за узел, «Ветеран» — 100).

## Контроль здоровья экономики (плейтест)

| Метрика | Цель |
| --- | --- |
| Неистраченные е-бали в конце уровня | < 20% всего дохода |
| Продажи за уровень | 0–5 (иначе дорого ошибаться или скучно) |
| Доля ★★ и выше у плейтестеров | ≥ 60% |
| Узлов дерева открыто к ур. 10 при ★★ | все платные, кроме 2–4 «Ветеранов» |
