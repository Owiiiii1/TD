# Дороги и движение врагов

**Статус:** черновик · **Пиллары:** 3, 5 · **Система:** S02 · **TDD:** будет позже

## Кратко

Наземный враг едет по заранее проложенным маршрутам — от точки появления до рубежа. Маршруты задаются при создании уровня, игрок не может их перекрыть или изменить. Игрок управляет только тем, насколько трудно врагу по ним пройти.

## Фантазия игрока

«Колонна ползёт по трассе прямо в мою засаду, и деться ей некуда».

## Правила

1. **Маршрут** — заранее заданная линия по клеткам «Дорога» (или «Вода» для кораблей) от точки появления до рубежа.
2. На карте может быть несколько маршрутов; они могут расходиться и сходиться на развилках.
3. Каждый враг при появлении получает один маршрут — его задаёт волна (S07). В пути маршрут не меняется.
4. Враг едет вдоль маршрута с собственной скоростью. Поиска пути нет: дорогу нельзя перекрыть, поэтому враг всегда доезжает, если его не уничтожили.
5. Враги не сталкиваются друг с другом и могут обгонять друг друга. Визуально они разведены по ширине дороги, чтобы колонна не сливалась в одну точку.
6. Дорожные препятствия (ежи и подобное) замедляют врага в своих клетках, но не останавливают.
7. Враг, доехавший до рубежа, исчезает и снимает очки рубежа (S09).
8. Враг, сделавший «жест доброй воли» (S16), разворачивается и едет по своему маршруту назад к точке появления, после чего исчезает.

## Состояния и переходы

| Состояние | Переход |
| --- | --- |
| Появился | → Едет, сразу |
| Едет | → Замедлен, при входе в зону замедления; → Отступает, при «жесте доброй воли»; → Уничтожен; → Дошёл |
| Замедлен | → Едет, при выходе из всех зон замедления |
| Отступает | → Ушёл, у точки появления; → Уничтожен |
| Дошёл | Снимает рубеж и исчезает |
| Уничтожен / Ушёл | Исчезает (обломки — S17) |

## Формулы

**Скорость с замедлением:**
`скорость = базовая скорость × (1 − сильнейшее замедление)`
Замедления не складываются: действует самое сильное.
Пример: базовая 2 клетки/с, ежи 40% и ведьмы 25% → 2 × (1 − 0,4) = 1,2 клетки/с.

**Прогресс по маршруту:** пройденная доля пути от 0 (появление) до 1 (рубеж). По нему наведение выбирает «самого близкого к рубежу».

## Крайние случаи

- Два маршрута сходятся → враги с обоих едут по общему участку без столкновений.
- Враг отступает и проходит через препятствие → замедление действует и на отступающих.
- Враг появляется, когда игрок поставил препятствие прямо на точку появления → запрещено: препятствия не ставятся на клетки появления и рубежа.
- Ускорение игры ×2 → скорость и замедления масштабируются вместе со временем, логика не меняется.

## Фидбек

- Перед уровнем и перед каждой волной вдоль маршрутов пробегают стрелки; у точек появления — значки врагов следующей волны.
- Враг в зоне замедления — эффект (пыль, буксует у ежей).
- Отступающий враг — белый флаг или характерная анимация «жеста доброй воли».
- Враг доходит до рубежа — короткая тревожная вспышка у рубежа и звук.

## UI

- Значки появления следующей волны на краю экрана, если точка не видна в камере.
- Подсветка маршрута при наведении на врага.

## Критерии приёмки

- [ ] На тестовой карте с двумя маршрутами враги едут каждый по своему маршруту от появления до рубежа.
- [ ] Враги не упираются друг в друга и не застревают.
- [ ] Препятствие на дороге замедляет врага на заданный процент; два препятствия разом не складываются.
- [ ] Препятствие нельзя поставить на точку появления и рубеж.
- [ ] Враг, дошедший до рубежа, исчезает и снимает очки рубежа.
- [ ] Перед волной видно, по каким маршрутам она пойдёт.
