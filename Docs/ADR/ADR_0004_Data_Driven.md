# ADR-0004 — Данные в DataAsset, мягкие ссылки, Gameplay Tags

## Статус
Принято

## Контекст
Баланс TD — это сотни чисел (юниты, враги, волны, дерево). Их меняет владелец без программиста.

## Решение
- Все числа баланса — в DataAsset. В C++ нет чисел баланса.
- Типы DataAsset: юнит, враг, супер-удар, уровень (сетка, маршруты, волны, тексты), дерево технологий, запись энциклопедии, таблица урона, общие настройки (экономика, мораль, трофеи, звёзды), конфиг камеры.
- Контент (модели, звуки, классы) — мягкими ссылками (`TSoftObjectPtr`, `TSoftClassPtr`), загрузка через Asset Manager при старте уровня.
- Классы целей, типы урона, свойства врагов — Gameplay Tags (`TD.Target.*`, `TD.Damage.*`, `TD.Trait.*`), без строк в коде.

## Последствия
### Плюсы
- Баланс правится в Editor без пересборки.
### Минусы
- Нужна валидация данных (IsDataValid) — закладываем в каждый DataAsset.
