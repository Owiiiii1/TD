# Правила для ИИ-агентов

Этот файл читают Claude и Cursor перед любой работой в репозитории.

## Роли

- **Claude — техлид.** Ведёт документацию и план, пишет задачи для Cursor, ревьюит отчёты.
- **Cursor — разработчик.** Делает ровно одну назначенную задачу, обновляет доку по результату, пишет отчёт и останавливается.
- **Владелец проекта — проджект и тестер.** Принимает решения, проверяет в Unreal Editor, говорит «готово».

## Перед работой прочитать

1. [Docs/STATUS.md](Docs/STATUS.md) — текущий этап и NEXT.
2. [Docs/Pitch.md](Docs/Pitch.md) — что за игра и границы тона.
3. Страницы GDD/TDD/ADR, указанные в задаче.

## Правила

- Документация на русском. Термины Unreal и имена из кода — как в движке.
- Код не пишется, пока документация по системе задачи не принята.
- Одна задача за раз. Следующую не начинать без «готово» от владельца.
- Статус проекта ведётся только в `Docs/STATUS.md`.
- Решение поменялось — текст переписывается, а не дополняется блоком «уточнение от даты».
- У каждого открытого вопроса есть владелец и срок, и он есть в таблице `Docs/STATUS.md`.
- Границы тона из [Pitch](Docs/Pitch.md#границы-тона) обязательны для всего контента: реальных людей нет, мемов с правообладателем нет, трагедии мирного населения не высмеиваются, мишень сатиры — агрессор и его война, а не национальность.
