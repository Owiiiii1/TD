# Оборонительные юниты

**Статус:** черновик · **Пиллары:** 1, 3, 5, 4 · **Система:** S04 · **TDD:** будет позже

## Кратко

Оборона — это расчёты, техника и сооружения, которые игрок ставит на сетку. Каждый юнит — реальная модель с простой ролью: по пехоте, по броне, по воздуху, по площади, по морю, замедление или тыл. Юниты стоят на месте и стреляют сами.

## Фантазия игрока

«Моя оборона — это ТрО, Javelin, Stinger и бабушка с банкой огурцов. И она работает».

## Правила

1. Юнит ставится на свободные клетки «Земли» (S01) за е-бали (S03) и стреляет автоматически (S05).
2. У юнита одна роль и один тип урона. Подсказка роли — одна строка.
3. Юнит не двигается, у него нет прочности: уничтожить его нельзя, можно только подавить (S05).
4. Каждый юнит улучшается до уровня II в бою за е-бали. Уровень III открывается в дереве технологий (S22) и даёт особое свойство.
5. Юнит продаётся с возвратом части вложенных е-балей (S03).
6. Новые юниты открываются в дереве технологий по хронологии. Ключевой юнит уровня выдаётся бесплатно, если игрок его не открыл (S22).
7. Дорожные препятствия ставятся только на клетки «Дорога» и замедляют врага (S02).
8. Трофейная техника ставится бесплатно жетоном, полученным в этом уровне (S17).

## Формулы

`урон на уровне = базовый урон × (1 + 0,4 × (уровень − 1))`
Пример: Javelin III: 110 × 1,8 = 198.

## Параметры тюнинга

Все числа таблицы ростера и улучшений живут в DataAsset юнита: урон, перезарядка, радиус, минимальная дальность, радиус взрыва, цена, размер, классы целей, свойство уровня III.

## Крайние случаи

- Юнит улучшают во время перезарядки → новый урон со следующего выстрела.
- Продажа юнита во время выстрела → снаряд долетает.
- Ежи на клетке, где сейчас враг → ставятся, замедление действует сразу.

## Фидбек

- Постройка: юнит «высаживается» с короткой анимацией и звуком.
- Улучшение: шеврон над юнитом, вспышка.
- Выстрел: у каждого юнита узнаваемый звук; Javelin — дуга сверху.

## UI

- Панель постройки по категориям: Пехота и ПТ, Артиллерия, ПВО, Тыл и препятствия.
- Подсказка: имя, роль одной строкой, иконки целей, цена, радиус.
- Панель выбранного юнита: уровень, улучшить, продать, приоритет цели, «В энциклопедию».

## Критерии приёмки

- [ ] Все юниты этапа 1 ставятся, стреляют по своим классам целей и не стреляют по чужим.
- [ ] Улучшение до II увеличивает урон на 40%; уровень III недоступен без дерева.
- [ ] Ежи ставятся только на дорогу и замедляют на 40%.
- [ ] Подсказка каждого юнита помещается в одну строку роли.
