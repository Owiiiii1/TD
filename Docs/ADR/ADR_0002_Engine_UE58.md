# ADR-0002 — Unreal Engine 5.8 и C++ с Blueprint для визуала

## Статус
Принято

## Контекст
Владелец знает Unreal; GrimProtocol написан на UE 5.8, из него переносится камера и практики. Игра одиночная, ПК, 3D.

## Решение
- Движок: Unreal Engine 5.8 (последний патч 5.8.x на момент старта; точный патч фиксируется в задаче TD-001).
- Геймплей — C++. Blueprint — наследники для визуала, настройки ассетов и UI-вёрстки.
- Баланс и контент — DataAsset (ADR-0004).
- Платформа сборки — Win64 (Development, Shipping).

## Последствия
### Плюсы
- Перенос кода из GrimProtocol без конвертации.
- Cursor пишет C++, владелец собирает и проверяет в Editor.
### Минусы
- Сборка C++ медленнее чистого Blueprint-прототипа.

## Рассмотренные альтернативы
- Unity/Godot — теряется наработка GrimProtocol.
- Чистый Blueprint — плохо ревьюится и хуже для ИИ-разработки.
