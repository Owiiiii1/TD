# Волны

**Статус:** черновик · **Пиллары:** 3, 5, 1 · **Система:** S07 · **TDD:** будет позже

## Кратко

Уровень состоит из 8–15 волн. Волна — набор групп врагов: кто, сколько, по какому маршруту и с каким интервалом. Между волнами идёт таймер, который игрок может сократить, вызвав волну раньше за бонус. Состав следующей волны виден заранее.

## Фантазия игрока

«Вижу, что следующей идёт колонна брони по южной дороге — успеваю перестроиться».

## Правила

1. Волны уровня заданы заранее в данных уровня и одинаковы при каждом прохождении. Случайности нет, кроме вариантов внешности врагов.
2. Волна состоит из групп. Группа: тип врага, количество, маршрут, интервал между врагами, задержка от начала волны.
3. Перед первой волной таймера нет: игрок строит сколько хочет и запускает волну кнопкой.
4. Между волнами — таймер (стартовое значение 25 с). По окончании таймера волна начинается сама.
5. **Ранний вызов:** кнопка «Следующая волна» запускает волну сразу и даёт бонус е-балей за оставшиеся секунды таймера.
6. Следующая волна может начаться, пока предыдущая ещё на поле.
7. **Предпросмотр:** до начала волны игрок видит, какие враги и по каким маршрутам пойдут, и их количество.
8. Последняя волна уровня обычно содержит босса или главную угрозу события (S15).
9. Волна считается пройденной, когда все её враги уничтожены, ушли (S16) или дошли до рубежа.
10. Бонус за волну начисляется, когда волна пройдена.

## Состояния и переходы

| Состояние | Переход |
| --- | --- |
| Подготовка (до первой волны) | → Волна, по кнопке |
| Волна | → Таймер, когда все группы волны появились |
| Таймер | → Волна, по окончании таймера или по кнопке (с бонусом) |
| Последняя волна пройдена | → Победа (S09) |

## Формулы

**Бонус раннего вызова:** `бонус = оставшиеся секунды × 1 е-бал`. Пример: вызвал за 18 с до конца → +18.
**Бонус за пройденную волну:** `20 + 5 × номер волны`. Пример: волна 6 → +50.

## Параметры тюнинга

| Параметр | Стартовое значение | Диапазон | Где живёт |
| --- | --- | --- | --- |
| Количество волн | 8–15 | 5–20 | Данные уровня |
| Таймер между волнами | 25 с | 10–60 | Данные уровня |
| Бонус раннего вызова | 1 е-бал/с | 0–3 | Общие настройки экономики |
| Бонус за волну | 20 + 5 × N | — | Общие настройки экономики |

## Крайние случаи

- Ранний вызов на последней волне → кнопка недоступна.
- Две волны на поле одновременно → бонус каждой начисляется отдельно по её завершении.
- Пауза останавливает таймер.

## Фидбек

- Начало волны: сирена, баннер «Волна 4 из 12».
- Предпросмотр: значки врагов у точек появления и стрелки маршрутов.
- Ранний вызов: «+18 е-балей» и звук.

## UI

- Счётчик волн и таймер вверху; кнопка «Следующая волна» с бонусом на ней.
- Панель предпросмотра: иконки врагов с количеством; при наведении — имя и класс цели.

## Критерии приёмки

- [ ] Волны идут в заданном порядке, группы — по своим маршрутам и с интервалами.
- [ ] Таймер запускает волну сам; кнопка запускает раньше и даёт бонус.
- [ ] Предпросмотр показывает состав следующей волны.
- [ ] После последней пройденной волны срабатывает победа.

## Плейтест-сценарии

| Сценарий | Ожидание |
| --- | --- |
| Опытный игрок вызывает волны рано | Получает заметно больше е-балей, рискует |
| Новичок не нажимает кнопку | Волны идут по таймеру, уровень проходится |

## Вне MVP

- Бесконечный режим со случайными волнами.
- Разная сложность волн по выбору игрока (см. 31_Balance_Difficulty).
