# UI — архитектура

**Статус:** черновик · **GDD:** [40_UI_UX](../GDD/40_UI_UX.md) · **ADR:** [0009](../ADR/ADR_0009_UI_CommonUI_MVVM.md)

## Обзор

Экраны — CommonUI activatable widgets в стеке. Данные — ViewModel (MVVM), которые подписываются на делегаты `ATD_GameState`, `UTD_CampaignSubsystem` и компонентов контроллера. Виджеты не обращаются к акторам напрямую.

## ViewModel

| ViewModel | Источник | Поля |
| --- | --- | --- |
| `UTD_HUDViewModel` | GameState, WaveDirector | Е-бали, рубеж (и %), волна N/M, таймер, бонус раннего вызова, предпросмотр волны, скорость, пауза |
| `UTD_BuildPanelViewModel` | Campaign, GameState | Доступные юниты по категориям, цена, доступность по е-балям |
| `UTD_SelectedUnitViewModel` | BuildComponent | Имя, уровень, цена улучшения, доступен ли III, сумма продажи, приоритет |
| `UTD_StrikesViewModel` | SuperStrikeComponent | Удары, перезарядка, готовность |
| `UTD_BossBarViewModel` | GameMode | Имя и прочность босса |
| `UTD_EventFeedViewModel` | События боя | Лента: новая запись, трофей, жест доброй воли |
| `UTD_CampaignMapViewModel` | Campaign | Уровни, звёзды, доступность |
| `UTD_BriefingViewModel` | LevelData | Тексты, справка, что нового |
| `UTD_ResultViewModel` | GameMode, Campaign | Звёзды, рубеж, «Набито», донаты, новые записи |
| `UTD_TechTreeViewModel` | Campaign, TechTreeData | Узлы, состояние, цены, донаты |
| `UTD_EncyclopediaViewModel` | Campaign, EntryData | Разделы, записи, прогресс |

## Экраны

`WBP_TD_MainMenu`, `WBP_TD_CampaignMap`, `WBP_TD_Briefing`, `WBP_TD_HUD`, `WBP_TD_PauseMenu`, `WBP_TD_Result`, `WBP_TD_Defeat`, `WBP_TD_TechTree`, `WBP_TD_Encyclopedia`, `WBP_TD_Settings`.

## Локализация

String Tables `ST_TD_UI`, `ST_TD_Units`, `ST_TD_Enemies`, `ST_TD_Levels`, `ST_TD_Encyclopedia`; культуры uk (основная), en. В DataAsset — `FText` из String Tables.

## Правила

- Никакого текста в C++ и текстурах.
- Обновление по делегатам, не по Tick (кроме таймеров перезарядки — через таймер UI 10 Гц).
- UI работает на паузе.

## Тесты

- Ручная: все экраны на 1920×1080 и 2560×1440, смена языка на лету.
