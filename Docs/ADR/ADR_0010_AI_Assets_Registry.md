# ADR-0010 — Реестр ассетов и раскрытие ИИ-контента

## Статус
Принято

## Контекст
Ассеты MVP генерируются ИИ (GDD/50). Steam требует раскрывать сгенерированный контент в игре, на странице и в маркетинге.

## Решение
- Реестр ассетов `Docs/Development/Asset_Registry.md`: ассет, путь, источник (сгенерирован / вручную / покупной), инструмент, лицензия, автор доработки.
- Ассет без записи в реестре не попадает в билд (проверка при ревью).
- Перед публикацией страницы Steam — раздел AI Generated Content Disclosure по реестру.

## Последствия
Прозрачность для Steam и для юридических вопросов по лицензиям генераторов.
