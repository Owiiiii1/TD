# ADR-0009 — UI: CommonUI + MVVM

## Статус
Принято

## Контекст
Много экранов (меню, карта, брифинг, HUD, дерево, энциклопедия, настройки) с навигацией и вводом. В GrimProtocol используется CommonUI + MVVM, опыт есть.

## Решение
- Экраны — CommonUI (`UCommonActivatableWidget`), стек экранов.
- Данные в виджеты — через ViewModel (плагин ModelViewViewModel). Виджеты не читают игровые акторы напрямую.
- Вёрстка — Blueprint-виджеты `WBP_TD_*` над C++-базой из `TDUIRuntime`.
- Все строки — String Tables (uk, en).

## Последствия
### Плюсы
- Готовая навигация и ввод, переиспользуемый опыт GrimProtocol.
### Минусы
- Порог входа CommonUI выше голого UMG — компенсируется опытом.
