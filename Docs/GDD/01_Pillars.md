# Пиллары

**Статус:** черновик

Пиллары — неподвижные правила, которые держат идентичность игры. Каждое решение по механике, контенту и арту проверяется по ним. Блок «Запрещает» — главный фильтр: решение, которое в него попадает, не принимается без пересмотра пиллара.

## Порядок при конфликте

Если два пиллара тянут в разные стороны, побеждает тот, что выше:

1. Сатира бьёт по агрессору (2).
2. Простое ядро, глубина из сочетаний (5).
3. Реальная война, мемная подача (1).
4. Свободная оборона на сетке (3).
5. Энциклопедия — награда (4).

Пример: реальная техника требует сложной механики (пиллар 1), но её нельзя объяснить в двух предложениях (пиллар 5) — механику упрощаем, реализм остаётся в карточке энциклопедии.

---

## 1. Реальная война, мемная подача

**Суть.** Всё узнаваемое — реальное: события, места, техника, вооружение. Подача — мемная и мультяшная, а не документальная.

### Цель игрока
Узнавать знакомые события и технику и проживать их в победной и смешной форме.

### Разрешает
- Уровни по реальным событиям с реальными названиями мест и датами.
- Реальные модели техники с узнаваемым силуэтом в мультяшном стиле.
- Мемы войны как механики, внешний вид юнитов и тексты.
- Игровые упрощения характеристик ради баланса; реальные цифры живут в энциклопедии.

### Запрещает
- Вымышленную технику и вымышленные события вместо реальных.
- Реальных людей: политиков, командиров, военных, блогеров.
- Мемы с правообладателем («Святая Джавелина», NAFO, песня «Байрактар», бренды компаний).
- События после середины 2025 года без отдельной проверки.

### Проверка по 5 компонентам
| Компонент | Что это значит |
| --- | --- |
| Понятность | Игрок узнаёт технику по силуэту и подписи, событие — по брифингу |
| Мотивация | Хочется увидеть следующее знакомое событие |
| Отклик | Узнаваемые мемные реакции на действия: трактор уезжает с танком, корабль тонет |
| Удовлетворение | Момент «это же то самое!» |
| Целостность | Реальные модели в едином мультяшном стиле |

## 2. Сатира бьёт по агрессору

**Суть.** Враг — карикатура на армию-агрессор, без смягчений. Наши — герои. Мишень сатиры — агрессор и его война, а не национальность и не жертвы.

### Цель игрока
Смеяться над врагом и чувствовать гордость за своих.

### Разрешает
- Карикатурных врагов в образе орков-свиней, мародёрство, трусость, «жест доброй воли».
- Высмеивание армии, командования, государства-агрессора, пропаганды, имперских мифов, «Z»-символики, сторонников войны.
- Героические карточки и подачу наших юнитов.

### Запрещает
- Высмеивание людей по национальности.
- Юмор над жертвами войны и мирным населением.
- Трагедии с массовыми жертвами среди мирных как уровни (Буча, Мариуполь, Каховская ГЭС, Оленовка).
- «Добрых» или сочувственных врагов.
- Высмеивание наших юнитов, кроме самоиронии из самих мемов (бабушка с огурцами).

### Проверка по 5 компонентам
| Компонент | Что это значит |
| --- | --- |
| Понятность | Свой и чужой различаются мгновенно: цвет, силуэт, поведение |
| Мотивация | Каждое уничтожение врага — маленькая шутка |
| Отклик | Враги гибнут смешно: роняют награбленное, разбегаются |
| Удовлетворение | Подписи и реплики врага после поражения |
| Целостность | Один тон во всём: брифинги, энциклопедия, UI |

## 3. Свободная оборона на сетке

**Суть.** Враг идёт только по дорогам. Игрок строит оборону в любой свободной клетке квадратной сетки — без фиксированных слотов. Главное решение — где и что поставить.

### Цель игрока
Найти свою расстановку: перекрыть дороги огнём, создать «мешки», прикрыть уязвимые места.

### Разрешает
- Постройку юнитов в любой свободной клетке вне дорог.
- Препятствия на дорогах, которые замедляют врага, но не перекрывают путь.
- Разные размеры юнитов в клетках (1×1, 2×2).
- Угрозы, которые обходят дороги: авиация, десант.

### Запрещает
- Фиксированные слоты под башни.
- Перекрытие дороги до полной блокировки пути (лабиринты не наша механика).
- Свободное перемещение юнитов по карте в бою (это не RTS).
- Микроконтроль каждого юнита во время волны.

### Проверка по 5 компонентам
| Компонент | Что это значит |
| --- | --- |
| Понятность | Сетка и зоны поражения видны при постройке |
| Мотивация | Удачная расстановка — заслуга игрока |
| Отклик | Юнит ставится мгновенно, зона подсвечивается |
| Удовлетворение | Колонна входит в «мешок» и тает |
| Целостность | Позиции выглядят как реальная оборона: окопы, укрытия, ежи |

## 4. Энциклопедия — награда

**Суть.** Каждый юнит обеих сторон — реальная модель с карточкой. Открытие карточек — коллекционная награда за прохождение.

### Цель игрока
Собрать энциклопедию целиком и узнать, что за техника стоит за юнитами.

### Разрешает
- Карточку на каждый тип юнита и врага: реальная модель, факты, игровые характеристики, мем.
- Открытие карточки при первой встрече или первом уничтожении.
- Пасхалки и редкие вариации (пехотинец с унитазом) как отдельные записи.

### Запрещает
- Юниты без карточки.
- Карточки с выдуманными реальными фактами.
- Платный или внеигровой доступ к карточкам.

### Проверка по 5 компонентам
| Компонент | Что это значит |
| --- | --- |
| Понятность | Видно, сколько открыто и что осталось |
| Мотивация | Пустые карточки тянут дальше |
| Отклик | Уведомление «Новая запись» в бою |
| Удовлетворение | Смешная подпись к вражеской карточке |
| Целостность | Героический тон у наших, сатирический у врагов |

## 5. Простое ядро, глубина из сочетаний

**Суть.** Каждая механика объясняется в 1–2 предложениях. Глубина появляется из сочетания простых юнитов, врагов и угроз, а не из сложных правил.

### Цель игрока
Понять игру за минуты и находить сильные сочетания сам.

### Разрешает
- Механики, понятные без отдельного туториала.
- Новые уровни и юниты как новый контент, а не новые правила.
- Простые роли: дальний, ближний, ПВО, замедление, против брони, против пехоты.

### Запрещает
- Механики длиннее 2 предложений объяснения.
- Ресурсы кроме одного (донаты) в MVP.
- Деревья прокачки, крафт, характеристики юнитов на десятки параметров.
- Механику, которая не даёт игроку нового решения.

### Гейт механики
Каждая новая механика отвечает «да» на большинство вопросов:
1. Весело уже в первой версии?
2. Понятно новичку за 1–2 предложения?
3. Даёт новый тип решения?
4. Можно сделать дёшево и быстро?
5. Масштабируется контентом, а не новыми правилами?

### Проверка по 5 компонентам
| Компонент | Что это значит |
| --- | --- |
| Понятность | Подсказка юнита — одна строка |
| Мотивация | Новые сочетания открываются с каждым уровнем |
| Отклик | Результат решения виден в ту же волну |
| Удовлетворение | Своё найденное сочетание работает |
| Целостность | Сложность растёт вместе с войной: этап за этапом |
