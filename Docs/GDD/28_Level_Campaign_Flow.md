# Поток уровня и кампании

**Статус:** черновик · **Пиллары:** 1, 2, 4 · **Система:** S18 · **TDD:** будет позже

## Кратко

Игрок идёт по кругу: карта кампании → брифинг → уровень → итог → дерево технологий → следующий уровень. Прогресс сохраняется автоматически после каждого уровня и покупки.

## Фантазия игрока

«Шаг за шагом прохожу весну 2022-го».

## Правила

1. **Главное меню:** Продолжить, Кампания, Энциклопедия, Настройки, Выход.
2. **Карта кампании:** карта Украины с отметками уровней этапа; пройденные — со звёздами, следующий — подсвечен, остальные закрыты. Кнопки «Технологии» и «Энциклопедия».
3. **Брифинг:** название события, место, дата; 2–3 строки с юмором; кнопка «Справка» с одним абзацем серьёзного фактического контекста (уважительно, без шуток); что нового в уровне (новый враг, юнит, удар). Кнопка «В бой».
4. **Уровень:** подготовка → волны → победа или поражение (S07, S09).
5. **Итог:** звёзды, оставшийся рубеж, уничтожено врагов («Набито» — счётчик), донаты, новые записи энциклопедии; кнопки «Дальше», «Технологии», «Переиграть».
6. **Поражение:** «Всё идёт по плану» — «Заново», «На карту».
7. Уровни открываются по порядку; пройденные можно переигрывать.
8. **Сохранение:** автоматически после итога уровня и после покупки в дереве. Один профиль, без ручных слотов. Прогресс внутри уровня не сохраняется.
9. **Справка о событии** доступна и позже — в энциклопедии, раздел «События».

## Состояния и переходы

| Экран | Переходы |
| --- | --- |
| Главное меню | → Карта кампании, Энциклопедия, Настройки |
| Карта кампании | → Брифинг, Дерево, Энциклопедия, Главное меню |
| Брифинг | → Уровень, Карта кампании |
| Уровень | → Итог (победа), Поражение, Пауза-меню |
| Пауза-меню | → Уровень, Заново, Настройки, Карта кампании |
| Итог | → Карта кампании, Дерево, Уровень (переиграть) |

## Параметры тюнинга

Данные уровня: название, место, дата, текст брифинга (uk/en), справка (uk/en), что нового, точка на карте.

## Крайние случаи

- Выход из уровня в меню → прогресс уровня теряется, предупреждение.
- Игра закрыта во время уровня → при запуске — карта кампании, прогресс до уровня сохранён.

## Фидбек

- Переход на карту после победы: следующий уровень «загорается».

## Критерии приёмки

- [ ] Цикл карта → брифинг → уровень → итог → дерево проходит без тупиков.
- [ ] Прогресс сохраняется и загружается после перезапуска.
- [ ] Справка о событии доступна в брифинге и в энциклопедии.

## Вне MVP

- Сохранение посреди уровня.
