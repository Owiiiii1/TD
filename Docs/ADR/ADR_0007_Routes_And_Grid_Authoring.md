# ADR-0007 — Маршруты сплайнами, сетка из объёмов уровня

## Статус
Принято

## Контекст
Враги ходят по заранее заданным маршрутам, без поиска пути (GDD/11). Сетку с 7 типами клеток нужно задавать удобно, без ручной покраски сотен клеток.

## Решение
- Маршрут — актор `ATD_Route` со `USplineComponent`. Тип: наземный, водный, воздушный.
- Сетка — актор `ATD_LevelGrid` (один на уровень): размер поля, размер клетки, начало координат.
- Типы клеток вычисляются при загрузке уровня (и превью в Editor):
  - «Дорога» / «Вода» — клетки, через которые проходят наземные / водные маршруты (ширина задаётся на маршруте);
  - «Препятствие», «Зона высадки» — по объёмам `ATD_GridVolume` с типом;
  - «Появление», «Рубеж» — начала и концы маршрутов;
  - остальное — «Земля».
- Движение врага — по расстоянию вдоль сплайна; разброс по ширине — смещение по нормали.

## Последствия
### Плюсы
- Уровень собирается за минуты: проложил сплайны, поставил объёмы.
- Нет навмеша и поиска пути — дёшево и предсказуемо.
### Минусы
- Нужна визуализация сетки в Editor для проверки — закладываем в TD-003.
